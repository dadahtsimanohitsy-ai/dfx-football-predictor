# DFX Football Predictor

Prototype de site web mobile inspiré du design Drellibet / football virtuel.

## Démarrage

1. Ouvrez le dossier `dfx-football-predictor`
2. Lancez `index.html` dans un navigateur
3. Le design se charge directement et reste compatible mobile

## Ce qui est inclus

- interface sombre premium
- onglets de ligues
- carte de match principale
- score prédit
- 1 / N / 2
- analyse des buts
- marchés Over / Under / BTTS
- design responsive mobile-first
